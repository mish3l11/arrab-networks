NETWORK DICTIONARY

📖 قاموس الشبكات

مرجع سريع لأهم مصطلحات الشبكات بطريقة بسيطة وسهلة للفهم.

🌐 أساسيات الشبكات

IP Internet Protocol

عنوان منطقي يُستخدم لتحديد الجهاز والوصول إليه داخل الشبكة.

MAC Media Access Control

عنوان فريد مرتبط ببطاقة الشبكة ويُستخدم داخل الشبكة المحلية.

LAN Local Area Network

شبكة محلية تربط الأجهزة في مكان محدود مثل المنزل أو المكتب.

WAN Wide Area Network

شبكة واسعة تربط شبكات أو مواقع موجودة في مناطق مختلفة.

WLAN Wireless LAN

شبكة محلية لاسلكية تعتمد على الاتصال عبر Wi-Fi.

VLAN Virtual LAN

تقسيم منطقي للشبكة إلى شبكات منفصلة بدون الحاجة إلى فصلها فعلياً.

TCP Transmission Control Protocol

بروتوكول يعتمد على الاتصال الموثوق ويضمن وصول البيانات بالترتيب.

UDP User Datagram Protocol

بروتوكول سريع لا يحتاج إلى إنشاء اتصال قبل إرسال البيانات.

ICMP Internet Control Message Protocol

بروتوكول يُستخدم لرسائل الشبكة واختبار الاتصال مثل أمر Ping.

MTU Maximum Transmission Unit

أكبر حجم لحزمة البيانات يمكن إرسالها عبر واجهة الشبكة.

🔀 Switching

STP Spanning Tree Protocol

بروتوكول يمنع حدوث Loop بين السويتشات.

RSTP Rapid Spanning Tree Protocol

نسخة أسرع من STP لتقليل وقت استعادة الشبكة بعد حدوث تغيير.

LACP Link Aggregation Control Protocol

بروتوكول يجمع عدة روابط في رابط منطقي واحد.

EtherChannel EtherChannel

تقنية Cisco لدمج عدة منافذ في رابط منطقي واحد.

Trunk Trunk Port

منفذ يسمح بمرور أكثر من VLAN عبر نفس الرابط.

Access Access Port

منفذ يُستخدم عادةً لتوصيل جهاز نهائي داخل VLAN واحدة.

CAM Content Addressable Memory

ذاكرة في السويتش تُستخدم لتخزين عناوين MAC والمنافذ المرتبطة بها.

FDB Forwarding Database

جدول يستخدمه السويتش لمعرفة المنفذ المرتبط بعنوان MAC.

BPDU Bridge Protocol Data Unit

رسائل تستخدمها بروتوكولات STP لتبادل معلومات حالة الشبكة.

PVID Port VLAN ID

رقم VLAN الافتراضية المرتبطة بالمنفذ للـ Untagged traffic.

🛣️ Routing

OSPF Open Shortest Path First

بروتوكول Routing ديناميكي يعتمد على حالة الروابط.

BGP Border Gateway Protocol

بروتوكول يستخدم لتبادل مسارات الشبكات بين الأنظمة المستقلة.

RIP Routing Information Protocol

بروتوكول Routing يعتمد على عدد القفزات كـ Metric.

AS Autonomous System

مجموعة شبكات تعمل تحت إدارة Routing واحدة.

AD Administrative Distance

قيمة تساعد الراوتر في اختيار مصدر المسار المفضل.

Metric Routing Metric

قيمة يستخدمها بروتوكول التوجيه للمفاضلة بين المسارات.

Next-Hop Next Hop

عنوان الجهاز التالي الذي سيتم إرسال الحزمة إليه.

Default Route Default Route

مسار يستخدم عندما لا يوجد مسار أكثر تحديداً للوجهة.

FIB Forwarding Information Base

جدول يستخدمه الجهاز لاتخاذ قرار تمرير الحزم بسرعة.

VRF Virtual Routing and Forwarding

يسمح بإنشاء جداول Routing مستقلة داخل نفس الجهاز.

🔐 Security

ACL Access Control List

مجموعة قواعد تسمح أو تمنع أنواعاً معينة من حركة الشبكة.

SSH Secure Shell

بروتوكول آمن للدخول وإدارة أجهزة الشبكة عن بُعد.

AAA Authentication Authorization Accounting

إطار لإدارة المصادقة والصلاحيات وتسجيل نشاط المستخدمين.

802.1X IEEE 802.1X

معيار للتحكم في وصول الأجهزة إلى الشبكة باستخدام المصادقة.

VPN Virtual Private Network

اتصال منطقي آمن يسمح بربط المستخدم أو الشبكة بشبكة أخرى.

NAT Network Address Translation

تقنية لترجمة عناوين IP بين شبكات مختلفة.

PAT Port Address Translation

نوع من NAT يسمح لعدة أجهزة بمشاركة عنوان IP واحد.

IDS Intrusion Detection System

نظام يراقب الشبكة لاكتشاف الأنشطة المشبوهة أو محاولات الاختراق.

IPS Intrusion Prevention System

نظام يكتشف الأنشطة المشبوهة ويمكنه منعها.

Port Security Port Security

ميزة للتحكم في عناوين MAC المسموح لها باستخدام منفذ السويتش.

🛠️ Troubleshooting & Services

DHCP Dynamic Host Configuration Protocol

بروتوكول يوزع إعدادات الشبكة مثل IP وGateway وDNS تلقائياً.

DNS Domain Name System

يحول أسماء المواقع مثل example.com إلى عناوين IP.

ARP Address Resolution Protocol

بروتوكول يستخدم لمعرفة عنوان MAC المرتبط بعنوان IPv4.

QoS Quality of Service

تقنيات لإدارة أولوية وتدفق البيانات داخل الشبكة.

SNMP Simple Network Management Protocol

بروتوكول يستخدم لمراقبة وإدارة أجهزة الشبكة.

Syslog System Logging Protocol

نظام لتجميع وتسجيل رسائل وأحداث الأجهزة.

NTP Network Time Protocol

بروتوكول لمزامنة الوقت بين أجهزة الشبكة.

PoE Power over Ethernet

تقنية تسمح بتمرير الطاقة الكهربائية عبر كابل الشبكة.

Ping Ping

أداة لاختبار إمكانية الوصول بين جهازين عبر الشبكة.

Traceroute Traceroute

أداة تعرض المسار الذي تسلكه الحزم للوصول إلى الوجهة.
