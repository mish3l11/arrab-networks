NETWORK DICTIONARY

📖 قاموس الشبكات

أهم اختصارات ومصطلحات الشبكات مع الاسم الكامل والمعنى بالعربي.

🌐 أساسيات الشبكات

IP Internet Protocol

بروتوكول يستخدم لعنونة الأجهزة وتوجيه البيانات.

MAC Media Access Control

عنوان فريد لواجهة الشبكة يستخدم للتعرف على الجهاز داخل الشبكة.

LAN Local Area Network

شبكة محلية تربط الأجهزة ضمن نطاق جغرافي محدود.

WAN Wide Area Network

شبكة واسعة تربط شبكات ومواقع جغرافية مختلفة.

WLAN Wireless Local Area Network

شبكة محلية لاسلكية تعتمد على الاتصال عبر Wi-Fi.

VLAN Virtual Local Area Network

تقسيم منطقي للشبكة إلى شبكات منفصلة داخل السويتش.

TCP Transmission Control Protocol

بروتوكول نقل موثوق يضمن وصول البيانات بالترتيب الصحيح.

UDP User Datagram Protocol

بروتوكول نقل سريع لا يعتمد على إنشاء اتصال مسبق.

ICMP Internet Control Message Protocol

يستخدم لرسائل التحكم والتشخيص مثل اختبار الاتصال باستخدام Ping.

MTU Maximum Transmission Unit

أكبر حجم لحزمة البيانات يمكن إرسالها عبر الواجهة دون تجزئة.

🔀 Switching

STP Spanning Tree Protocol

بروتوكول يمنع حدوث حلقات الشبكة بين السويتشات.

RSTP Rapid Spanning Tree Protocol

نسخة أسرع من STP لتقليل وقت استعادة الشبكة.

LACP Link Aggregation Control Protocol

بروتوكول يستخدم لتجميع عدة روابط في رابط منطقي واحد.

EtherChannel EtherChannel

تقنية لتجميع عدة وصلات Ethernet في قناة واحدة.

Trunk Trunk Link

وصلة تسمح بمرور عدة VLANs عبر رابط واحد.

Access Access Port

منفذ سويتش مخصص عادةً لـ VLAN واحدة.

CAM Content Addressable Memory

ذاكرة يستخدمها السويتش لتخزين معلومات عناوين MAC والمنافذ.

FDB Forwarding Database

جدول يحتوي على معلومات تساعد السويتش في تمرير الإطارات.

BPDU Bridge Protocol Data Unit

رسائل تستخدمها بروتوكولات STP لتبادل معلومات الشبكة.

PVID Port VLAN ID

رقم VLAN المرتبط بالإطارات غير الموسومة على المنفذ.

🛣️ Routing

OSPF Open Shortest Path First

بروتوكول توجيه ديناميكي يعتمد على حالة الروابط.

BGP Border Gateway Protocol

بروتوكول توجيه يستخدم لتبادل معلومات المسارات بين الأنظمة المستقلة.

RIP Routing Information Protocol

بروتوكول توجيه ديناميكي يعتمد على عدد القفزات.

AS Autonomous System

مجموعة من الشبكات تحت إدارة واحدة وتستخدم سياسة توجيه مشتركة.

AD Administrative Distance

قيمة تستخدم لتحديد موثوقية مصدر مسار التوجيه.

Metric Routing Metric

قيمة يستخدمها بروتوكول التوجيه لاختيار المسار المناسب.

Next-Hop Next Hop

عنوان الجهاز التالي الذي تمر إليه حزمة البيانات.

Default Route Default Route

مسار يستخدم عندما لا يوجد مسار أكثر تحديدًا للوجهة.

FIB Forwarding Information Base

جدول يستخدم لاتخاذ قرارات تمرير الحزم.

VRF Virtual Routing and Forwarding

تقنية تسمح بوجود جداول توجيه مستقلة على نفس الجهاز.

🔐 Security

ACL Access Control List

قائمة قواعد للتحكم في حركة المرور المسموح بها أو الممنوعة.

SSH Secure Shell

بروتوكول آمن للوصول وإدارة أجهزة الشبكة عن بُعد.

AAA Authentication, Authorization and Accounting

إطار لإدارة التحقق من الهوية والصلاحيات وتسجيل النشاط.

802.1X IEEE 802.1X

معيار للتحكم في الوصول إلى الشبكة بناءً على التحقق من هوية المستخدم أو الجهاز.

VPN Virtual Private Network

تقنية لإنشاء اتصال خاص وآمن عبر شبكة عامة.

NAT Network Address Translation

تقنية لترجمة عناوين IP بين شبكات مختلفة.

PAT Port Address Translation

نوع من NAT يسمح لعدة أجهزة بمشاركة عنوان IP واحد باستخدام أرقام المنافذ.

IDS Intrusion Detection System

نظام يراقب الشبكة لاكتشاف الأنشطة المشبوهة.

IPS Intrusion Prevention System

نظام يراقب التهديدات ويمكنه منع الأنشطة الضارة.

Port Security Switch Port Security

ميزة لحماية منافذ السويتش والتحكم في عناوين MAC المسموح بها.

🛠️ Troubleshooting & Services

DHCP Dynamic Host Configuration Protocol

بروتوكول يوزع إعدادات الشبكة مثل IP تلقائيًا على الأجهزة.

DNS Domain Name System

نظام يحول أسماء النطاقات إلى عناوين IP.

ARP Address Resolution Protocol

بروتوكول يستخدم لمعرفة عنوان MAC المرتبط بعنوان IPv4.

DNS Domain Name System

خدمة تساعد الأجهزة على الوصول إلى الخدمات باستخدام أسماء النطاقات.

QoS Quality of Service

تقنيات لإدارة أولوية حركة المرور وجودة الخدمات على الشبكة.

SNMP Simple Network Management Protocol

بروتوكول لمراقبة وإدارة أجهزة الشبكة.

Syslog System Logging Protocol

آلية لإرسال وتسجيل رسائل وأحداث الأجهزة والأنظمة.

NTP Network Time Protocol

بروتوكول لمزامنة الوقت بين أجهزة الشبكة.

PoE Power over Ethernet

تقنية تسمح بنقل الطاقة الكهربائية عبر كابل Ethernet مع البيانات.

ICMP Internet Control Message Protocol

يستخدم في تشخيص الاتصال وإرسال رسائل التحكم والأخطاء.
